# Doclix Autofill
Android Autofill Service for saved profile data.
- Android 8.0+ (API 26)
- Uses AssistStructure parsing and Autofill Framework.
- Build: GitHub Actions workflow produces a debug APK artifact.
- Enable on phone: Settings → Autofill service → Doclix Autofill.
This is a development build; real identity data should be encrypted before production.
